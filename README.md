# ISTA AI — UI Preview (Static Mirror)

Static UI preview of **ISTA AI** (Laravel + Livewire document workspace & AI
assistant, built during an internship at Istana Kepresidenan Yogyakarta),
for the portfolio of Muhammad Hasbi Ash Shiddiqi.

**Live preview:** https://portofolio-hasbi.web.id/ista-demo/

## What this is

The pages were rendered by the real application and mirrored to static HTML —
same markup, same compiled CSS/JS. Included: the dashboard, the chat workspace,
the profile page, and the login page. The AI backend (FastAPI service), document
data, and authentication do not run in this preview; forms are neutralized with a
small demo script and no real documents or user data are included (the preview was
rendered from an empty, freshly seeded local install).

Production ISTA AI runs only inside the Istana's local environment; this preview
exists so the interface can be seen publicly.
